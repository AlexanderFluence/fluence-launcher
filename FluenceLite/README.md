# Fluence Lite

Launcher liviano para la radio Android (Android 10). Sin librerías externas, sin mapa, sin
fondo animado y sin animaciones entre pantallas.

- **Inicio:** hora, fecha, RAM libre y 6 accesos grandes: CarPlay · AA (ZLink), Spotify, Mapas,
  Radio, Apps y Optimizar. Mantén presionado un acceso para cambiar su app.
- **Optimizar:** libera memoria cerrando apps en segundo plano (nunca ZLink, Spotify, CANbus,
  Bluetooth, cámara ni servicios de la radio), lista las apps que se pueden desactivar y marca
  las que se inician solas al encender.

El APK se compila solo con GitHub Actions al subir cambios en `FluenceLite/` y queda en
**Releases** como `FluenceLite.apk`.
